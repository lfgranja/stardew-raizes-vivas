## Research Notes

- **Seams** (Feathers, *Working Effectively with Legacy Code*, 2004): a place where behavior can be altered without editing the code in that place. Three types: object seams (polymorphism/virtual dispatch), preprocessing seams, link seams.
- **Humble Object** (Feathers 2002, Meszaros *xUnit Test Patterns* 2007): keep the SMAPI-facing adapter trivially thin; move all logic into pure, framework-agnostic services. Variants: Humble Dialog/Executable/Transaction Controller/Container Adapter, Poor Man's/True/Subclassed.
- **Dependency Injection** (Meszaros): Parameter/Constructor/Setter injection; constructor injection is the project standard (ModEntry sole composition root).
- **SMAPI mod testability**: project's own seams (Domain layer SMAPI-free, providers wrapping `Game1.*`, pure domain services `OrganicWasteValidator`/`SeasonalDecayMultiplier`, `InternalsVisibleTo`). Pathoschild's `Tests.Common`/`Tests.Mods` pattern.
- **xUnit + FsCheck**: `[Property]` attribute, `Check.QuickThrowOnFailure`, generators, `Machine` model-based stateful testing for stateful game mechanics (composting bin, soil health cache).
- **Internal seam design** (internal-seam.md): recommended interface with 4 methods; types in `LivingRoots.Domain`; impl in `LivingRoots.Domain.Services`; pure, stateless; references `ModConstants` for boost values; inventory-full encoded as delivery policy (`MainItemBlocked`, `ExtraItemDroppedAsDebris`).
- **Feedback conditionality (B1/B2)**: "Living Soil" only when enhanced quality or extra harvest; both as two sprites when both hold; Moderate/Unknown none. Because feedback depends on rolled outcome, seam exposes `ResolveFeedback(decision, enhancedQualityOccurred, extraHarvestOccurred)`.
- **Crop scope (A6)**: early return for forage/fibre/Qi; fruit trees, giant crops, tea bushes, ground forage out of scope (not `Crop` instances).
- **NaN/Unknown (A3)**: no modification; measured 0 → Poor → force 0 (A7).
- **Inventory full (A1)**: main item vanilla-blocked; extra item debris (vanilla semantics, no mod override).
- **Pest clamp (A5)**: optional, null-safe, echoed `int?`.
- **Host authority (A8)**: replicated deterministic roll; seam pure/deterministic given inputs.
