## Research Notes

- SMAPI multiplayer: host is authoritative for shared farm state; farmhands use `SendMessage`/`ModMessageReceived` only when a mod needs custom sync; this mod needs none for rolls (computes locally from shared `SoilHealthService` tile health) (research-c2, research-c1).
- `Game1.multiplayer.broadcastSprites` is the MP-safe path for transient sprites; game state is not synced by it (internal-c2 §2.4).
- First-wins semantics: second concurrent action re-evaluated; refused with message if no longer valid; inventory intact (Constitution Principle VI; spec A5).
- Live 2-player verification is owed to roadmap D1; automated stubs attest to mechanism only (Constitution Principle VI: "MUST NOT be presented as live multi-player proof").
- Debris created via `Game1.createItemDebris` syncs through the location's normal debris sync (vanilla); mod adds no custom sync (research-c1).
