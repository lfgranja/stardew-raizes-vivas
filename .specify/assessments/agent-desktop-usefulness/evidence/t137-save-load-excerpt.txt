## Why the bundle artifact looked like a 5-second stall

`scripts/lib/signals.sh` (`signals_smapi_log_excerpt`) greps only for:

```text
elapsed
SoilGrowthModifierCompleted|DayEnding
not main player
```

so `artifacts/smapi-log.txt` contains only the two `Instance_*` elapsed lines and
looks like the game stopped. The full log shows otherwise.
